# APOD Home Page

A little cosmos in every new tab. A small Chrome extension that puts the daily **Astronomy Picture of the Day** and its explanation above your familiar site shortcuts.

No API key, account, subscription, hosted backend, or build step needed. The extension is plain HTML, CSS, and JavaScript.

## Install in Chrome

1. Download this repository with **Code → Download ZIP**, then unzip it (or clone it).
2. Open `chrome://extensions` in Chrome.
3. Turn on **Developer mode** in the top-right corner.
4. Click **Load unpacked** and select the **`extension` folder** inside this repository, the one containing `manifest.json`.
5. Open a new tab. If Chrome asks whether to keep this New Tab change, choose **Keep it**.

Keep that folder on your computer: Chrome loads the extension from it. If you update the files, click the extension's reload button at `chrome://extensions`, then open a new tab.

If you use the release ZIP generated by this project, unzip it and load the extracted folder directly; its `manifest.json` is at the root.

**Opening Chrome:** this replaces the New Tab page. To see it when launching Chrome, choose **Settings → On startup → Open the New Tab page**. Chrome's “Continue where you left off” option still restores your previous tabs.

## What you get

- The daily APOD picture, shown in full without cropping, plus its title, credit, and explanation.
- A centered date above the picture, with previous/next arrows to browse published APODs. **Today** returns to the latest picture and retries a failed update. Future days are disabled until published.
- A compact caption with **Read explanation** to expand the full text.
- Up to ten automatically populated most-visited site icons in a familiar row.
- **Customize → My shortcuts** to add, rename, remove, and reorder up to twenty sites. **Copy most visited** is a starting point for a fixed list.
- Light, dark, or device appearance; light is the default.
- Cached APOD text and URLs for quick new tabs, an hourly freshness check, and a check after Eastern midnight. Browsing the archive does not change what appears in your next new tab.
- A helpful fallback on video days: the explanation and a link to watch the original APOD, with no autoplay or embedded player.

Chrome's [topSites API](https://developer.chrome.com/docs/extensions/reference/api/topSites) supplies most-visited sites but **does not expose shortcuts you manually customized in Chrome's original New Tab page**. Add those once in Customize. The extension recreates the site row; it does not edit Chrome's built-in page in place. Your address bar, bookmarks bar, and default search engine continue to work normally.

## APOD sources and failures

The extension first tries [apod.com/en/](https://apod.com/en/). If the mirror is unavailable or its HTML format is unrecognized, it tries [NASA's APOD page](https://science.nasa.gov/apod/). It extracts text and image URLs; it does not embed the source website or run its scripts.

Both sources can publish late or become unavailable. If a fetch fails, the last successful APOD remains visible with a status message. With no saved picture, shortcuts still work and **Today** can retry. Failed daily updates retry after five minutes while the page is visible; **Today** can retry immediately. The displayed date comes from the source, so an older APOD is not relabeled as today's picture. Archive pages are fetched from the dated mirror or located through NASA's public archive endpoint, and their dates are checked before displaying them.

Only text and image URLs are stored locally. Image availability offline depends on Chrome's HTTP cache; this is **not a guaranteed offline image archive**. If the image cannot load, the explanation and source link remain available.

## Privacy and permissions

No analytics, tracking, ads, or application server. Preferences and cached APOD metadata stay in `chrome.storage.local` in your browser profile; they are not synced or included in repository files.

| Permission | Purpose |
| --- | --- |
| `topSites` | Show Chrome's most-visited sites. These are never sent to APOD. |
| `favicon` | Retrieve site icons through Chrome's built-in favicon endpoint, rather than an external icon service. |
| `storage` | Save preferences, custom shortcuts, and the last APOD metadata locally. |
| `https://apod.com/*` | Read the daily APOD mirror page. |
| `https://science.nasa.gov/*` | Read the NASA fallback page. |

APOD servers receive the usual requests for their pages and images. The picture itself may be hosted on a different HTTPS domain linked by APOD. Images load with no referrer. No browsing history, cookies, tabs, or arbitrary-site access permission is requested. Read [PRIVACY.md](PRIVACY.md) for details.

## Limitations and troubleshooting

- To hide Chrome's own bottom banner showing **APOD New Tab**, right-click the banner and choose **Hide footer on New Tab page**, or turn off **Show footer on New tab page** in **Customize Chrome**. This is a Chrome preference; extension code cannot hide Chrome's separate UI. See [Chrome's announcement](https://groups.google.com/a/chromium.org/g/chromium-extensions/c/DNj1B3vywr0/m/X5nOP0gPAQAJ).
- Chrome supports one active New Tab replacement at a time. Disable another New Tab extension if it takes precedence.
- Chrome's Incognito New Tab page cannot be overridden by this type of extension.
- A personally loaded unpacked extension is local to the Chrome profile where you install it. It is not automatically installed on your other devices.
- Google-only New Tab features such as the Doodle and AI cards are replaced by the APOD layout. Search using Chrome's address bar.
- If Chrome displays “Failed to load extension,” select the folder containing `manifest.json`, not the repository's outer folder.
- To restore the original Chrome page, disable or remove **APOD New Tab** at `chrome://extensions`. Removing the extension deletes its locally saved settings.
- If a source changes its HTML layout, update `extension/lib/apod.js` and its parser checks. Unrecognized HTML is rejected rather than saved as a blank APOD.

## Development

Installation requires no development tools. To contribute, use Node.js 22+ and Python 3 for packaging:

```sh
npm ci
npm test
npx playwright install chromium
npm run test:browser
npm run package
```

The browser tests load the real unpacked extension in a disposable Chromium profile with controlled network responses; they never change your personal Chrome profile. They check parsing, NASA fallback, archive navigation and date matching, safe rendering, video days, cached/offline states, URL validation, shortcut editing and persistence, and responsive layout. `APOD_BROWSER_EXECUTABLE` can point to an existing Chromium binary for local testing. GitHub Actions runs both test suites and uploads the extension ZIP.

`npm run package` writes `dist/apod-new-tab-1.0.0.zip` containing the extension, license, privacy policy, and README. Upload this ZIP to a GitHub release for easy sharing. The repository itself is also ready to publish to any GitHub repository; no user-specific links, credentials, or local browser data are included.

```
extension/           Install this folder in Chrome
  lib/apod.js        Classic mirror and NASA HTML parsers; source fallback
  lib/model.js       URL validation, settings, and cache freshness
  newtab.*           Page layout and behavior
tests/               Dependency-free unit checks and Chromium integration checks
scripts/package.py   Package the extension for a release
```
